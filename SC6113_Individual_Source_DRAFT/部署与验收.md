## 1 部署合约（你确认钱包操作，我提供指引）

1. 电脑 Chrome 中打开 MetaMask，启用测试网络并选择 **Sepolia**。手机钱包可操作 App，首次部署建议电脑。
2. 确认账户有少量 Sepolia 测试 ETH。没有时使用可信水龙头；不要购买主网 ETH 来完成本作业。
3. 在 https://remix.ethereum.org 打开 Remix，新建 `Donation.sol`，粘贴本文件夹 `contracts/Donation.sol` 全文。
4. Solidity Compiler 选择 **0.8.30**，Advanced Configurations 的 EVM Version 选 **Shanghai**，启用 optimizer，runs **200**，编译。
5. Deploy & Run 选择 **Injected Provider - MetaMask**，确认 Remix 和 MetaMask 都显示 Sepolia，Value 为 0，选择 Donation。
6. 点击 Deploy，在钱包核对并确认。构造函数没有参数，部署者自动成为组织者。
7. 保存部署交易哈希、合约地址和部署区块号（可在 Sepolia Etherscan 回执查看）。这三项是公开信息，可以发给我。不要发送任何私钥或助记词。
8. 保存钱包连接和部署成功截图。合约不要部署到 Ethereum Mainnet。

## 2 发布 Flask 服务

整个 `individual-assignment` 文件夹作为独立项目根目录（不要上传 `.venv`、`node_modules`、缓存或 `.env`）。其中静态前端由 Flask 同时提供，避免跨域和双服务配置。

GitHub 上传此前受浏览器自动审批阻止，未成功。若该限制仍存在，需要你手动上传准备好的源码包，我可以继续指导。不要尝试用别的浏览器或命令绕过同一限制。

Render Python Web Service 设置：

- Build Command: `pip install -r requirements.txt`
- Start Command: `gunicorn --bind 0.0.0.0:$PORT --workers 2 --threads 4 --timeout 120 app:app`
- `RPC_URL`: `https://ethereum-sepolia-rpc.publicnode.com`
- `CONTRACT_ADDRESS`: 部署得到的合约地址
- `DEPLOYMENT_BLOCK`: 部署区块的十进制数字
- 免费方案（如果页面仍提供）。此项目不需要连接以前的 PostgreSQL 数据库。

服务地址尚未创建，不能把原 ChainCard 链接称为新版。部署后验证 `/health` 的 configured 为 true，并且网页确实显示链上余额、组织者和合约链接。
